# 制作資料パッケージ
- docs/仕様書_Ver2.1.md : 正式なゲーム詳細仕様
- references/ : 生成したコンセプトボード（雰囲気参考）
- wireframes/ : 主要6画面の縦型UIワイヤーフレーム

注意：キャラクターPNGはコンセプトボードから切り出した仮の胸上ポートレートです。全身透過イラストや表情差分は含みません。背景は楕円マスクで透明化しており、人物輪郭の厳密な切り抜きではありません。参考ボード内の数値は仕様書と異なる場合があるため、正式値は仕様書を優先してください。
